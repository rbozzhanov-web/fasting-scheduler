# Fuel Window

Лёгкий PWA-планировщик интервального голодания для пилотского расписания.

- Режимы 12:12, 14:10, 16:8, 18:6
- Цели и контекст дня: отдых, тренировка, ранний/ночной duty, восстановление
- Локальная запись процента жира и тренда
- PDF выбирается с устройства и не загружается на сервер

Опубликованное приложение: **https://rbozzhanov-web.github.io/fasting-scheduler/**

## Публикация

В Settings → Pages включите Deploy from a branch, выберите main и папку root. После этого PWA будет доступно по адресу GitHub Pages выше.

## Локальное хранение и резервная копия

Roster, замеры и настройки хранятся только на устройстве (localStorage и IndexedDB) — своего сервера у приложения нет, и данные никуда не отправляются. Кнопка «Сохранить» в настройках выгружает их одним JSON-файлом (`{app, v, saved, state}`), кнопка «Восстановить» читает такой файл обратно. Резервную копию стоит держать в «Файлах» или iCloud: на iOS удаление ярлыка с экрана «Домой» стирает все данные веб-приложения без возможности восстановления.

## Ограничения на iOS

- **Уведомления** работают только после добавления приложения на экран «Домой» (standalone-режим) — иначе iOS не разрешает их вовсе. Без этого события видны лишь при открытом приложении.
- **Напоминания в календарь** добавляются через открытие `.ics`-файла, а не через меню «Поделиться» (Календаря там нет на iOS): основной путь — обычная ссылка на файл, который отдаёт service worker. Повторное открытие обновляет те же события, не создавая дубликатов.
- **Обновление приложения**: iOS восстанавливает свёрнутый PWA из памяти без перезагрузки страницы, поэтому проверка новой версии выполняется вручную — при запуске и при каждом возврате на экран.

## Формат roster

Импорт распознаёт PDF-роспись конкретного макета (Air Astana): первая страница, шапка с периодом вида `ДД/ММ/ГГГГ - ДД/ММ/ГГГГ` и строка с датами дьюти. Из известного словаря duty-кодов распознаются `OFF`, `DOFF`, `ROFF`, `HOMS`, `HOMX`, `AVLB`, `VAC`, `CSH`, `MED*` и коды рейсов; аэропорты сверяются с встроенным списком IATA-кодов. Ростеры другого макета или авиакомпании парсер не поддерживает.

Это не медицинское приложение. Во время duty приоритет — сон, самочувствие и безопасная работоспособность.
