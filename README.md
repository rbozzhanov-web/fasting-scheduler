# Fuel Window

Лёгкий PWA-планировщик интервального голодания для пилотского расписания.

- Режимы 12:12, 14:10, 16:8, 18:6
- Цели и контекст дня: отдых, тренировка, ранний/ночной duty, восстановление
- Локальная запись процента жира и тренда
- PDF выбирается с устройства и не загружается на сервер
- AI-пояснение получает только минимальную сводку дня через личный AI-шлюз

## Публикация

В Settings → Pages включите Deploy from a branch, выберите main и папку root. После этого PWA будет доступно по адресу GitHub Pages.

## AI

В PWA не хранится ключ API. Укажите URL личного AI-шлюза, который принимает POST JSON и возвращает JSON с полем text. Шлюз должен хранить ключ модели в секретах, ограничивать CORS доменом PWA и не логировать запросы.

Это не медицинское приложение. Во время duty приоритет — сон, самочувствие и безопасная работоспособность.
